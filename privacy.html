Privacy Policy for rclone-oyxc

Effective date: October 30, 2026

Who operates this client

rclone-oyxc is a private OAuth client operated by Jayson_O for personal use only. The only Google account that uses it is the owner's own account.

What data is accessed

The client requests the Google Drive read-only scope (https://www.googleapis.com/auth/drive.readonly). This allows rclone to list and download the owner's Google Drive files. It cannot upload, modify or delete any files.

How the data is used

Files are downloaded by rclone and stored on the owner's personal home server, solely as a backup copy of the owner's own data.

Sharing and storage

No data is sold, shared with, or transferred to any third party. No data is sent to the operator of this website or to any other server. Access tokens are stored only in a local configuration file on the owner's server.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
